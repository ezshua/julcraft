# План: Мультивалютность — вкладка «Финансы», цены в USD

**Статус:** на рассмотрении (ничего не реализуется до утверждения)
**Тип задачи:** расширение настроек + новая логика хранения/отображения цен
**Связанные пункты плана:** `plan-2.md` §4 (Settings key-value), §5 (price-поля), §8 Этап 4 (T-4.6 настройки), §9 (открытые вопросы)
**Дата:** 2026-08-20

---

## 1. Цель

1. В настройках появляется 4-я вкладка **«Финансы»**: управление списком валют (добавление/удаление/редактирование), выбор валюты отображения по умолчанию.
2. Все цены в БД хранятся **только в долларах**.
3. Цены на сайте отображаются в выбранной валюте; переключатель валют добавляется на панель, где сейчас переключаются скины. Панель переименовывается **«Скин» → «Вид»**.
4. Ввод цен в админке — в выбранной валюте, в БД сохраняются доллары.
5. Существующие цены (сейчас в рублях) пересчитываются в доллары.
6. Валюта отображения по умолчанию — **гривна**.

## 3. Предлагаемые решения

| # | Вопрос | Предложение |
|---|---|---|
| D-15 | Как хранить доллары | **Центы (целое число, ×100)** во всех price-полях: `product.price = 2052` означает $20.52. Целочисленная арифметика без ошибок округления (привычная для денег). Альтернатива REAL — отклонена (плавающая точка для денег недопустима) |
| D-16 | Где хранить список валют | В `Settings` двумя ключами: `finance.currencies` (JSON) и `finance.defaultCurrency` (код) |
| D-17 | Доллар | Неудаляемый, `ratePerUsd = 1`, символ `$`, не редактируется только курс, а вот название и символ можно заменить |
| D-18 | Направление курса | `ratePerUsd` = сколько единиц валюты за 1 доллар (например рубль 95, гривна 41, евро 0.92). Конвертация: `USD→выбор: usdCents × rate / 100`; `выбор→USD: сумма × 100 / rate` (округление до цента) |
| D-19 | Формат отображения | Сумма с округлением до двух десятичных знаков + символ после числа: `1 950.00 ₴`, `2 050.00 ₽`, `21.00 $`. Символ из настроек валюты (₴ / ₽ / € / $) |
| D-20 | Панель «Вид» | Отступление от «skin-switcher.js копируется без изменений» (правило §0 / D-2): **одобрено руководителем**. Файл расширяется: подпись «Вид», блок скинов + блок валют |
| D-21 | Выбранная валюта | Хранится в `localStorage` + **cookie** (сервер должен рендерить цены в нужной валюте). При выборе — перезагрузка страницы (SSR перечитывает cookie) |
| D-22 | Стартовые курсы | Плейсхолдеры, уточнить (Q-1): USD `1`, EUR `0.92`, RUB `85`, UAH `44` |
| D-23 | Миграция существующих цен | Рубли → USD-центы по курсу рубля на момент миграции (по умолчанию 85), округление до цента. Затрагивает: `products.price`, `categories.workPrice`, `components.price`, `components.processingPrice`, `orders.calcPrice`. Старые snapshot `configJson` заявок **не трогаем** (исторический факт) |
| D-24 | Ввод цен в админке | Формы показывают значения в выбранной валюте (конвертация из USD при загрузке), при сохранении — обратная конвертация в USD-центы |
| D-25 | Курсы на клиенте | Новый публичный `GET /api/currency` → `{ currencies, default }` (нужен формам админки и калькулятору конфигуратора, Этап 5) |

## 4. Модель данных (новые ключи Settings)

```jsonc
// finance.defaultCurrency
"UAH"

// finance.currencies
[
  { "code": "USD", "name": "Доллар",  "symbol": "$",  "ratePerUsd": 1 },
  { "code": "UAH", "name": "Гривна",  "symbol": "₴",  "ratePerUsd": 44 },
  { "code": "RUB", "name": "Рубль",   "symbol": "₽",  "ratePerUsd": 85 },
  { "code": "EUR", "name": "Евро",    "symbol": "€",  "ratePerUsd": 0.92 }
]
```

- `code` — уникален, латиница, верхний регистр (ключ для cookie и расчётов).
- `USD` обязателен всегда: при любом редактировании списка он остаётся, удалить нельзя, `ratePerUsd` всегда `1`.
- Список может расширяться/сокращаться — кроме USD.

## 5. Шаги (после утверждения)

1. **`lib/currency.ts`** — типы (`Currency`, `CurrencySettings`), чтение списка валют и дефолта из Settings, конвертация (`usdToDisplay`, `displayToUsd`), форматирование, чтение выбранной валюты из cookie (сервер) / localStorage (клиент), fallback на дефолт.
2. **Настройки — таб «Финансы»** (`SettingsPanel.tsx`): таблица валют (код, название, символ, курс), кнопки добавить/удалить/сохранить; поле «Валюта отображения по умолчанию» (select); у USD недоступен только курс (всегда `1`), название и символ редактируемы. Расширение `KNOWN_KEYS` в `api/admin/settings/route.ts` ключами `finance.*`, валидация JSON и правил (USD неудаляем, `ratePerUsd` строго `1`, у остальных `rate>0`).
3. **`GET /api/currency`** (публичный) — список валют + дефолт для клиентских компонентов.
4. **Миграция цен** — скрипт `scripts/migrate-usd.ts`: конвертация всех price-полей рубль→USD-центы (D-23). Одновременно **правка `scripts/seed.ts`**: новые цены сразу в USD-центах (свежая БД консистентна).
5. **Отображение цен** — `formatPrice()` становится валютным: читает cookie/дефолт, конвертирует и форматирует (D-19). Обход всех мест с ценой (`ProductCard`, карточка товара, каталог, админские таблицы, чек заявки, дашборд, `order-success`). Замена жёстких «₽» в текстах home/catalog/configurator на вычисленные значения.
6. **Фильтр цен каталога** — границы перевести в USD (константа или в настройках), метки фильтров рендерятся в выбранной валюте (Q-4).
7. **Ввод цен в админке** — `ProductModal`, `ComponentModal`, `CategoryEditor`, `NewCategoryModal`: значение в выбранной валюте; при сохранении конвертация в USD (D-24). Подпись валюты у полей цены.
8. **Панель «Вид»** — `skin-switcher.js`: подпись `Вид`, кнопки скинов + кнопки валют (из `/api/currency` или инлайн-JSON). Выбор валюты: cookie + localStorage + перезагрузка. Стили панели — в том же стиле (не конфликтуют с CSS скинов).
9. **Уведомления Telegram** — сумма в тексте уведомления переводится в выбранную валюту (или помечается как USD) (Q-5).

**Приёмка:** цены на всех страницах меняются при переключении валюты на панели «Вид»; в БД все price-поля — только USD; ввод цены в админке в гривнах сохраняется корректным долларом; рубль→доллар миграция даёт ожидаемые значения на витрине.
