# Спецификация дизайна: 06.html — «Тёплое ручное тепло» (Вариант А)

> **Статус:** Финалист для выбора владельцем (Q-1 в plan-1.md)
> **Контекст:** Витрина мастерской JulCraft — авторские украшения, бижутерия, подбор
> **Стек реализации:** Next.js 14 + Tailwind + shadcn/ui (по plan-1.md §3)

---

## 1. Принцип построения (Design System)

**Методология:** «Старая лавка / вывеска 1970-х» — скеуморфизм кассовой ленты, деревянных полок, вывесок с тенью.
**Навигация:** Одностраничный лендинг (single-page scroll) с якорными ссылками.
**Сетка:** 1080px max-width, 3-колоночная витрина → 2 на планшете → 1 на мобильном.

---

## 2. Цветовая палитра (CSS Custom Properties)

| Переменная | Hex | Роль |
|---|---|---|
| `--cream` | `#f5edd8` | Фон body («pergament») |
| `--mustard` | `#d9a441` | Акцент: бордюр вывески, цена, тень hover |
| `--rust` | `#c05c33` | Акцент 2: тень заголовка, закрытые дни, тень карточек hover |
| `--olive` | `#6b7a3f` | Вторичный текст, часы работы, наличие |
| `--brown` | `#4a3226` | Основной текст, границы, кнопки, footer |

**Принцип:** Тёплые, «пыхнущие» оттенки дерева/кожи/бакелита. Никаких чистых чёрных/белых.

---

## 3. Типографика

| Элемент | Шрифт | Особенности |
|---|---|---|
| Display (h1, h2, h3 в карточках, footer) | **Shrikhand** (cursive, декоративный) | Крупные размеры `clamp()`, текстовая тень `4px 4px 0 var(--rust)` |
| Body / UI | **IBM Plex Mono** (monospace, 400/500) | Моноширинный — имитация печатной машинки / кассовой ленты |
| Метаданные (est, tag, price, avail) | IBM Plex Mono | `letter-spacing`, `text-transform: uppercase` |

**Иерархия:** Shrikhand — «вывеска», IBM Plex Mono — «чек/ярлык/ценник».

---

## 4. Компоненты и их поведение

### 4.1 Вывеска (`.signboard`)
- Полноэкранный заголовок на фоне `--brown` с нижним бордюром `--mustard` (10px)
- Псевдо-элементы по бокам: повторяющийся диагональный градиент (`repeating-linear-gradient`) — имитация обшивки/багетов
- H1: Shrikhand, `text-shadow: 4px 4px 0 var(--rust)` — объёмная типографика
- Зигзаг-разделитель (`.zigzag`) — CSS-паттерн из двух `linear-gradient` 135°/225°

### 4.2 Витрина / Полка (`.shelf` + `.item`)
- **Grid 3×1** → 2×2 → 1×3
- Карточка: белый фон, рамка 3px `--brown`, радиус 16px
- **Тень «приподнято»:** `box-shadow: 6px 6px 0 var(--mustard)` (не размытая, жёсткая — как картонная коробка)
- **Hover:** `translate(-3px, -3px)` + тень `9px 9px 0 var(--rust)` — карточка «соскакивает» вперед
- Фото: `object-fit: cover`, hover `scale(1.05) rotate(.6deg)` — лёгкий поворот «в живую»
- Инфо: название (Shrikhand), описание (мונו), строка тегов: цена (плюсовидный бейдж `--mustard`) + наличие (olive, uppercase)

### 4.3 Кассовый чек «О себе» (`.receipt`)
- Фон `--olive`, контейнер `#fdeed2` с `box-shadow: 8px 8px 0 rgba(0,0,0,.2)`
- **Маска верхнего края:** конусный градиент (`conic-gradient`) — зубчики чека
- Строки: `display: flex; justify-content: space-between`, пунктирное подчёркивание
- Штрих-код: `repeating-linear-gradient(90deg, ...)` — чисто CSS

### 4.4 Расписание / Часы (`.hours-board`)
- Панель на `--brown` с тенью `--rust`, радиус 16px
- Дни: flex, разделители `dotted`
- Кнопка телефона: `--rust` фон, рамка `--brown`, тень, hover `translate(-2px,-2px)`

### 4.5 Footer
- Центрирован, Shrikhand для названия, mono для адреса/года

## 8. Уникальные фишки (Signature Elements)

1. **Вывеска с тенью и багетами** — сразу задаёт тон «мастерская с историей»
2. **Кассовый чек как «About»** — метафора покупки/визита, запоминается
3. **Жёсткие тени (box-shadow без blur)** — стиль «плоский дизайн с глубиной», как вырезанные из картона слои
4. **Шрифт Shrikhand** — декоративный, но читаемый в крупных размерах, характерный для вывесок
5. **IBM Pex Mono везде** — усиляет эстетику «ярлыка/чека/печатной машинки»

---

## 9. Риски и доработки для продакшена

| Риск | Митигация |
|---|---|
| Shrikhand — декоративный, может утомлять в длинных текстах | Использовать **только** для заголовков (h1–h3), body — строго IBM Plex Mono |
| Жёсткие тени могут «резать» глаз на тёмных мониторах | Добавить `@media (prefers-reduced-motion)` и опциональную тему с мягчеми тенями |
| Нет состояний загрузки/ошибок для изображений | Добавить скелетоны (прямоугольники `--cream` с анимацией shimmer) |
| Форма заявки отсутствует | Реализовать модалку на React Hook Form + Zod (plan-1.md T-3.3) |
| SEO: нет metadata, OG, JSON-LD | Добавить в Next.js layout/page metadata |

## 11. Резюме: почему этот дизайн

**Сильные стороны:**
- Сильный брендинг: сразу понятно — «ручная работа, история, душа»
- Уникальные метафоры (вывеска, чек) отличают от шаблонов
- Лёгкий вес: весь CSS ~200 строк, без JS, быстрый FCP
- Хорошо масштабируется на каталог/карточки (компонент `.item` — универсален)

**Слабые стороны:**
- Одностраничный — нужен роутинг для каталога/админки
- Нет конфигуратора (потребует отдельного UI-кита)
- Моношрифт в body может снижать читаемость длинных текстов → нужен fallback на Nunito/Inter для абзацев >3 строк
