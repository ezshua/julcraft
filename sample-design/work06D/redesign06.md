## 1. Дизайн-система (расширение 06.html)

### 1.1 Цветовая палитра (обязательно к использованию)
```css
:root {
  --cream: #f5edd8;    /* фон body, пергамент */
  --mustard: #d9a441;  /* акцент 1: вывеска, цена, тени hover */
  --rust: #c05c33;     /* акцент 2: тени заголовков, закрыто, hover тени */
  --olive: #6b7a3f;    /* второстепенный текст, часы, наличие */
  --brown: #4a3226;    /* основной текст, границы, кнопки, footer */
  --white: #fff;       /* карточки, чек */
  --ink: #22242a;      /* ТОЛЬКО для штрих-кода / мелочей */
}
```
**Запреты:** Никаких чистых `#000`, `#fff` (кроме `.item` bg), холодных синих/зелёных. Только тёплая гамма дерева/кожи/бакелита/бумаги.

### 1.2 Типографика
| Роль | Шрифт | Веса | Размеры (clamp) |
|---|---|---|---|
| Display / H1 (вывеска, hero) | **Shrikhand** | 400 | `clamp(3rem, 9vw, 6.2rem)` |
| H2 (заголовки секций) | **Shrikhand** | 400 | `clamp(1.7rem, 4vw, 2.6rem)` |
| H3 (карточки товаров, блоки) | **Shrikhand** | 400 | `1.1rem` / `1.4rem` |
| Body / UI / Meta | **IBM Plex Mono** | 400, 500 | `0.8–1rem`, `line-height: 1.7` |
| Ценники / Бейджи / Uppercase | **IBM Plex Mono** | 500 | `0.72–0.85rem`, `letter-spacing: .1em` |

**Правило:** Shrikhand — **только** для заголовков. Весь читаемый текст (>2 строк) — IBM Pex Mono. Для длинных абзацев (About, Terms) допускается фоллбек на Nunito/Inter — согласовать с разработчиком.

### 1.3 Базовые UI-примитивы (переиспользуемые компоненты)

| Примитив | Описание | CSS-паттерн из 06.html |
|---|---|---|
| **Signboard** | Полноэкранный заголовок-вывеска | `.signboard` + `.zigzag` |
| **Card/Item** | Карточка товара/категории | `.item` — белый, рамка 3px `--brown`, радиус 16px, тень `6px 6px 0 --mustard` |
| **Receipt** | Блок «чек» (about, order-summary, success) | `.receipt` — маска зубчиков, пунктирные строки |
| **Board** | Панель с тенью (часы, фильтры, админ-таблицы) | `.hours-board` — `--brown` bg, тень `--rust` |
| **Btn-primary** | Кнопка действия (телефон, CTA, сабмит) | `.phone` — `--rust` bg, рамка `--brown`, тень, hover `translate(-2,-2)` |
| **Btn-secondary** | Вторичная (outline) | `--brown` рамка, transparent bg, hover `--brown` bg |
| **Tag/Price** | Бейдж цены/статуса | `.price` — `--mustard` bg, pill shape |
| **Zigzag** | Разделитель секций | `.zigzag` — CSS-паттерн 14px |
| **Input/Select** | Формы (модалки, админка) | Рамка 3px `--brown`, радиус 8px, фокус `--mustard` outline |

### 1.4 Тени и глубина (signature)
- **Нет blur** — только жёсткие `box-shadow: Xpx Xpx 0 COLOR`
- Уровни: `6px 6px 0 --mustard` (обычное), `9px 9px 0 --rust` (hover), `8px 8px 0 rgba(0,0,0,.2)` (чек)
- Анимации: только `transform: translate(-Xpx, -Ypx)` + смена тени. `transition: .25s`

### 1.5 Иконография
- Стиль: **линейные, моноширинные, грубоватые** — как штампы/гравировка
- Набор: телефон, почта, карта, инстаграм, телеграм, корзина/заявка, поиск, фильтр, стрелка, чекмарк, крестик, лупа, меню (burger)
- Размер: `1em` (для inline) / `24px` (для UI)

## 3. Навигация и глобальные элементы

### 3.1 Header (все публичные страницы)
- **Вариант А:** Нет классического header. Навигация — **прилипающая панель** (sticky top) в стиле `.signboard` но компактная:
  - Лево: Логотип (Shrikhand, `1.5rem`, `--cream` на `--brown`)
  - Центр: Навигационные якоря (Главная, Каталог, Конфигуратор, О нас, Контакты) — IBM Plex Mono, uppercase, `--mustard` hover
  - Право: Иконка телефона (клик → tel:), Иконка корзины/заявки (счётчик активных заявок — для админа)
- На мобильном: Burger → полноэкранное меню в стиле `.receipt` (список строк с пунктиром)

### 3.2 Footer (все публичные страницы)
- `.zigzag` разделитель
- Сетка 3 колонки: Лево — лого + адрес (Shrikhand + Mono), Центр — часы (мини `.hours-board`), Право — соцсети (иконки) + email/телефон
- Низ: копирайт, год, «с 1976 года (почти)»

### 3.3 Хлебные крошки (внутренние страницы)
- Строка: `Главная / Каталог / Броши / Брошь «Ромашковая»`
- Стиль: IBM Plex Mono `0.8rem`, `--olive` цвет, разделитель `›` (или `→`), текущая страница `--brown`

### 3.4 Состояния загрузки/ошибок/пустоты
- **Скелетон:** прямоугольники `--cream` с `border: 3px dashed --brown` + shimmer анимация (CSS-only)
- **Ошибка 404:** Signboard «Страница не найдена» + иконка сломанной броши + кнопка «На главную»
- **Пустое состояние (каталог/корзина):** `.receipt` карточка «Здесь пока пусто» + CTA

## 4. Специфические требования по ключевым фичам

### 4.1 Конфигуратор — детальный UI
| Элемент | Требование к макету |
|---|---|
| **Canvas-коллаж** | Область 1:1 (desktop) / 4:3 (mobile). Рамка 3px `--brown`. Фон `--cream`. Верхний бар: «Коллаж вашего украшения» + иконки «Скачать PNG» (админ), «Сбросить». Область drop-зоны для фото компонентов. |
| **Список слотов** | Accordion (по умолчанию открыт первый). Заголовок слота: название + min/max (Mono, `--olive`). Карточки компонентов: мини-`.item` (фото 60px, название, цена, бейдж наличия, qty stepper `-/+`). Недоступные (stock=0, not orderable) — затемнены, курсор not-allowed. |
| **Калькулятор (Sticky bottom / Sidebar)** | Крупные цифры: Цена (Shrikhand, `--brown`), Срок (Mono, `--olive`). Внутренний расчёт: «Работа: X ₽ + Компоненты: Y ₽ = Итого: Z ₽». «Срок: база N дн + компоненты M дн + доставка K дн = Итого L дн». Кнопка «Оформить заявку» — `.phone` стиль, full-width на мобильном. |
| **Модалка заявки** | `.receipt` стиль. Поля: Имя, Контакт (tel/email/telegram), Комментарий. Валидация inline (красная рамка `--rust`). Сабмит → спиннер в кнопке. Успех → редирект на `/order-success`. |

### 4.2 Модалка заявки на товар (из карточки изделия)
- Триггер: кнопка «Заказать» в `.product`
- Контент: `.receipt` с заголовком «Заявка на «Название»», фото товара (thumb), цена, форма (Имя, Контакт, Комментарий), сабмит
- Закрытие: Escape, клик по оверлею, крестик (стиль штампа)

### 4.3 Админ-таблицы (единый паттерн)
- Контейнер: `.board` (bg `--brown`, текст `--cream`, тень `--rust`)
- Заголовки: uppercase Mono `--mustard`
- Строки: `border-bottom: 1px dotted #7a6653`
- Ховер строки: `background: rgba(217,164,65,.1)`
- Действия: иконки (редактировать, удалить, посмотреть) — Mono символы `✎ 🗑 👁`
- Пагинация: простая, в стиле `.tag-row`
