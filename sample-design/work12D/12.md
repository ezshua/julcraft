# Спецификация дизайна: 12.html — «Геометрия, которую можно надеть» (Вариант Б)

> **Статус:** Финалист для выбора владельцем (Q-1 в plan-1.md)
> **Контекст:** Витрина мастерской JulCraft — конструкторская бижутерия
> **Стек реализации:** Next.js 14 + Tailwind + shadcn/ui (по plan-1.md §3)

---

## 1. Принцип построения (Design System)

**Методология:** «Мемфис / постомодерн / конструктор» — жирные геометрические формы, цветовые блоки, асимметрия, «конфетти» на фоне.
**Навигация:** Классический Header (Logo + Nav) + Hero + Секции + Footer. Многостраничный подход из коробки.
**Сетка:** 1240px max-width, 3-колоночная галерея → 2 на планшете (3-я карточка на всю ширину) → 1 на мобильном.

---

## 2. Цветовая палитра (CSS Custom Properties)

| Переменная | Hex | Роль |
|---|---|---|
| `--bg` | `#faf5ec` | Фон body (тёплый кремовый) |
| `--ink` | `#22242a` | Основной текст, границы, тени (почти чёрный) |
| `--c1` | `#e8b64c` | Жёлтый/горчичный — акцент 1 (тени карточек 1, кнопки fill, бейджи) |
| `--c2` | `#7fae9e` | Мятный/бирюзовый — акцент 2 (тени карточек 2, кнопки line, чип в заголовке) |
| `--c3` | `#d0785a` | Терракота/коралл — акцент 3 (тени карточек 3, чип 2, фото-рамка) |

**Принцип:** 3 акцентных цвета = 3 слота конфигуратора / 3 типа изделий. `--ink` — унифицирует границы и тени (все тени `8px 8px 0 var(--ink)`).

---

## 3. Типографика

| Элемент | Шрифт | Особенности |
|---|---|---|
| Display (h1, h2, h3, footer big, badge) | **Unbounded** (cursive, variable 400–800) | Жирный (`weight: 800`), крупные `clamp()`, использует лигатуры/альтернативы |
| Body / UI | **Nunito** (sans-serif, 400/600/700) | Скруглённый, дружелюбный, отличная читаемость |
| Чипы/Бейджи | Unbounded | Малые размеры, `transform: rotate(±2°)`, бордер `--ink` |

**Иерархия:** Unbounded — «геометрия/заголовки», Nunito — «текст/описания/кнопки».

---

## 4. Компоненты и их поведение

### 4.1 Фон «Конфетти» (`.confetti`)
- `position: fixed; inset: 0; z-index: -1; pointer-events: none`
- 4 `radial-gradient` круга разного размера/позиции (`--c1`, `--c2`, `--c3`) + диагональная полоса `linear-gradient(45deg)`
- `background-size` разные — создаёт эффект бесшовного паттерна без повторов
- **Принцип:** Чистый CSS, 0 байт изображений, анимировать можно через `background-position`

### 4.2 Header
- Logo: Unbounded 800, круглый индикатор `--c3` (`14px` диаметр)
- Nav: кнопки-п حبбки — белая подложка, рамка `--ink` 2.5px, `border-radius: 999px`
- **Hover:** `background: var(--c1); transform: rotate(-2deg)` — играет с «конструктором»

### 4.3 Hero (`.hero`)
- **Split-view:** Grid `1.05fr .95fr` (текст слева, фигура справа)
- H1: 3 строки, средние слова — **чипы** (`.chip`, `.chip--2`): фон `--c2`/`--c3`, белый текст, рамка `--ink`, поворот `±2°`
- CTA: 2 кнопки (`.btn--fill` + `.btn--line`)
  - Fill: `--ink` фон, белый текст, тень `--c1`
  - Line: белая подложка, `--ink` рамка, тень `--c2`
  - Hover: `translate(-2px,-2px)` + увеличение тени
- Правый блок: `.blob` — `border-radius: 58% 42% 48% 52%/52% 48% 52% 48%` (органическая форма), рамка 4px `--ink`, `rotate(3deg)`
- Бейдж (`.badge`): круг 130px, `--c1` фон, рамка `--ink`, текст Unbounded, `rotate(12deg)` — «стикер на фото»

### 4.4 Галерея / Карточки (`.cards` + `.card`)
- Grid 3×1, gap 34px
- Карточка: белая, рамка 3px `--ink`, радиус 24px
- **Тени по порядку:** `nth-child(1)` → `--c1`, `(2)` → `--c2`, `(3)` → `--c3` — цветовая навигация
- **Hover:** `translate(-4px,-4px) rotate(-1deg)` — карточка «съезжает» и поворачивается
- Фото: 260px высота, `object-fit: cover`, нижний бордер 3px `--ink`
- Футер карточки: фон `--bg`, верхний бордер 3px `--ink`, цена (Unbounded) + кнопка «→» (круг 38px, `--c1` фон, hover `rotate(-15deg) scale(1.1)`)

### 4.5 О мастере (`.about`)
- Фон `--ink`, белый текст, радиус 40px
- Grid `.85fr 1.15fr` (фото + текст)
- Фото в `.frame`: радиус 30px, `rotate(-2deg)`, белая рамка 4px, тень `--c3` 10px
- Заголовок: часть слова в `--c1` (`<span>`)
- Чипы (`.chips`): 4 бейджа с цветовым кодом (`.y`→`--c1`, `.g`→`--c2`, `.r`→`--c3`, последний нейтральный)

### 4.6 Footer
- Центрирован, Unbounded 800 для большого призыва, Nunito для контактов

## 5. Анимации и микро-взаимодействия

| Элемент | Transition | Эффект |
|---|---|---|
| Nav a | `.2s` | Поворот -2° + заливка `--c1` |
| `.btn` | `.2s` | Подъём + углубление тени |
| `.card` | `.25s` | Подъём + поворот -1° |
| `.card .go` | `.2s` | Поворот -15° + масштаб 1.1 |
| `.blob` / `.frame` | (статичны) | Начальный `rotate` задан в CSS |

**Принцип:** Всё через `transform` + `box-shadow`. Игровая, «конструкторская» физика — элементы немного кривые, живые.

## 8. Уникальные фишки (Signature Elements)

1. **Конфетти-фон на чистом CSS** — нулевой вес, бесконечный паттерн, задаёт настроение сразу
2. **Чипы в заголовке (H1)** — слово «можно» и «надеть» вынесены в цветные бейджи с поворотом — визуализация «конструктора»
3. **Органическая блоб-форма фото** (`border-radius` 8 значений) — не прямоугольник, не круг, «кусочек смолы»
4. **Цветовая кодировка тени карточек (c1/c2/c3)** — навигация по цвете без слов
5. **Кнопка «→» в карточке** — круг с поворотом при ховере, как «следующий шаг конструктора»
6. **Unbounded variable font** — позволяет тонко управлять весом (600/800) без загрузки нескольких файлов

## 9. Риски и доработки для продакшена

| Риск | Митигация |
|---|---|
| Unbounded — декоративный, в длинных текстах утомляет | Только заголовки (h1–h3, badge, footer big). Body — строго Nunito |
| Конфетти-фон может отвлекать / проблемы с доступностью | Добавить `@media (prefers-reduced-motion)` отключение, опцию «простой фон» в настройках |
| `mailto:` в кнопках карточек — не UX для заявок | Заменить на модалку React Hook Form + Zod (plan-1.md T-3.3) |
| Нет состояния загрузки изображений | Скелетоны: прямоугольники `--bg` с `border: 3px dashed --ink` + shimmer |
| SEO: нет metadata, OG, JSON-LD | Next.js metadata API на каждой странице |
| Форма обратной связи отсутствует | Добавить на `/contacts` + в модалке заявки |

## 11. Резюме: почему этот дизайн

**Сильные стороны:**
- Чёткая визуальная система: 3 цвета = 3 категории/слота — идеально ложится на **Конфигуратор** (plan-1.md §6)
- Hero сразу объясняет УТП: «геометрия → конструктор → надеть»
- Компонент `.card` идеален для каталога и конфигуратора (переиспользуем)
- Unbounded + Nunito — современная, доступная пара, хорошо смотрится в Tailwind
- Чистый CSS-фон — никаких загрузок, легко анимировать/переключать темы

**Слабые стороны:**
- Более «молодёжный/игровой» тон — может не зайти аудитории 45+ (целевая аудитория JulCraft уточнить по Q-1)
- Нет метафоры «мастерской/истории» — акцент на продукте, не на человеке
- `mailto:` вместо форм — технический долг с первого дня

---

**Рекомендация:** Подходит, если бренд = «современный конструктор, игра, цвет, геометрия». Для реализации — взять `.hero`, `.card`, `.about-grid`, `.confetti` как базовые блоки. Цветовая кодировка (c1/c2/c3) **прямо мапится на SlotTemplate компонентов конфигуратора** — это сильный архитектурный плюс.
