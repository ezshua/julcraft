# Задание агенту — i18n-5: Переводы демо-сида RU → EN/UK (4 мини-шага, data-only)

**Тип задачи:** контент (без кода)
**Зависимости:** i18n-2 · Шаги 1–7 (модель данных + вывод через L())
**Связанные пункты плана:** `plan-3.md` §4 (i18n-5), §5 D-i18n-4 (первый пакет — агент; боевой контент — мастер)
**Файлы зоны:** `site/scripts/seed.ts` (данные), — код не меняется, только значения

## Общие правила

- Каждый мини-шаг — data-only дифф `scripts/seed.ts`: значение `{ru: "..."}` становится `{ru: "...", en: "...", uk: "..."}`.
- Тон JulCraft сохранять: тёплый, лёгкий, «старая лавка» (см. существующие RU-тексты). EN — естественный английский, не подстрочник.
- Черновики ревьюятся руководителем на приёмке (список текстов — в отчёт).
- Идемпотентность: сид переразворачивается, `npm run check:seed` зелёный.

## Мини-шаги

- **5a. Категории, слоты, типы комплектующих** (~30 записей): названия + описания категорий, названия слотов («Основной камень», «Цепь или шнур»…), 6 типов.
- **5b. Комплектующие** (~25 записей): названия («Камень «Око бакелита»»…).
- **5c. Товары** (~16 записей): названия, описания, материалы, характеристики («Размер: 32 × 24 мм…», «Вес: 11 г — лёгкий, как утренние планы»).
- **5d. Settings-тексты:** чек знакомства (7+13 строк), 4 принципа, история (2 абзаца), подпись thanks, адрес (EN-транслит адреса — формат выбрать по смыслу), часы («выходной»).

## Критерии приёмки (per мини-шаг)

1. RU-витрина после переразворачивания сида — тексты идентичны прежним (RU не тронут).
2. EN-режим: все сущности шага показывают EN; UK-режим — UK; отсутствующий перевод → фолбэк ru (не должно быть пустых).
3. `npm run check:seed` зелёный; `npm run lint`, `npm run build`.

## Не делать (out of scope)

- Код сайта, словари UI (уже готовы), боевой контент БД (мастер заполняет сам через админку).
