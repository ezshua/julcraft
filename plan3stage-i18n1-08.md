# Задание агенту — i18n-1 · Шаг 8 из 12: Конфигуратор

**Тип задачи:** вынос строк в словарь (самая большая зона витрины, ~60 ключей)
**Зависимости:** i18n-1 · Шаг 1
**Связанные пункты плана:** `plan-3-i18n-constants.md` §1.5
**Файлы зоны:** `app/(public)/configurator/page.tsx`, `configurator/[slug]/page.tsx`, `components/configurator/ConfiguratorClient.tsx`, `CollageCanvas.tsx`, `OrderRequestModal.tsx`

## Цель

UI-строки конфигуратора — в словарь (namespace `configurator`). SEO (обе страницы) — шаг 11. Названия категорий/слотов/комплектующих из БД — i18n-2.

## Особое внимание

- **Словарь винительного падежа** (`ConfiguratorClient.tsx:33-41`): slug → «брошь/кулон/серьги/…» («Собираем {вин. падеж}»). Не переводится простым ключом: в словаре — таблица slug → {ru-вин., en, uk} (EN/UK падежей не имеют — там просто название). Хрупкое место, пометить в отчёте.
- «Слоты»-числительные (49, 139–143): «{N} слот/слота/слотов: {имена}» — plural + интерполяция.
- Калькулятор (247–321): «+ обработка», «в наличии», «под заказ · {N} дн», «{N} шт на складе», «Итого · цена», «Работа: {x} + Компоненты: {y}», «Срок изготовления», «день/дня/дней», «База {x} дн + обработка {y} дн + доставка {z} дн», title «Выберите компоненты» — все через plural/интерполяцию.
- Notice про формулы цены/срока (шаги page.tsx 13–105) — длинный текст, ключ с интерполяцией не нужен, просто вынести.

## Шаги

1. Ключи `configurator.*` по аудиту §1.5 (строки сверять с кодом): обе страницы (SEO-часть не трогать до шага 11) + все компоненты зоны.
2. Client-компоненты — словарь пропсами.
3. EN/UK — черновой перевод, список — в отчёт; тон «выберите форму — дальше Юля соберёт…» сохранить.

## Критерии приёмки

1. RU: конфигуратор (обзорная + страница категории с шаблоном слотов) текстово идентичен; пересчёт цены/срока на выбранных компонентах показывает те же строки, что раньше.
2. EN/UK: переключение переводит зону, plural «слот/день/шт» корректен.
3. Grep зоны — 0 кириллицы вне комментариев; `check:i18n`; `npm run lint`, `npm run build`.

## Не делать (out of scope)

- SEO (шаг 11), данные слотов/комплектующих (i18n-2), логика коллажа и расчётов не меняется.
