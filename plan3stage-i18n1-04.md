# Задание агенту — i18n-1 · Шаг 4 из 12: Обвязка layout (шапка, меню, футер, error-header, часы)

**Тип задачи:** вынос строк в словарь
**Зависимости:** i18n-1 · Шаги 1–3 (переключатель — для проверки)
**Связанные пункты плана:** `plan-3-i18n-constants.md` §1.1, §1.9
**Файлы зоны:** `components/layout/nav-links.ts`, `Header.tsx`, `MobileMenu.tsx`, `Footer.tsx`, `ErrorHeader.tsx`, `components/ui/HoursBoard.tsx`

## Цель

Все статические строки обвязки — в словарь (namespace `layout`), RU-тексты переносятся байт-точно, EN/UK — черновой перевод (ревью руководителем на приёмке).

## Правила

- RU-витрина визуально не меняется: только замена хардкода на `t()`. Точные строки брать из текущего кода (аудит мог дрейфовать).
- Client-компоненты (`Header`, `MobileMenu`) получают срез словаря `dict.layout` пропсами из server-layout.

## Шаги

1. Ключи `layout.*`: 5 пунктов меню (nav-links.ts), «Позвонить» + «Меню» (Header), «Закрыть» (MobileMenu), дни недели футера («Понедельник», «Вт — Пт», «Суббота», «Воскресенье»), «Часы работы», «Связаться», «мастерская украшений · эст. 2002 (почти)», «с 2002 года (почти) · © {year}» (год — интерполяция), ErrorHeader: пункты меню, «мастерская украшений», «Вход мастера» (+title, «→»-вариант), HoursBoard: «Часы работы».
2. Значения часов (интервалы, «выходной») — из Settings, их не трогать (это i18n-2); здесь только подписи-лейблы.
3. Заменить хардкод на `t()` во всех файлах зоны; словарь передать пропсами (`app/layout.tsx` и места использования ErrorHeader).

## Критерии приёмки

1. RU: шапка/меню/футер/404-обвязка визуально и текстово идентичны (сверка до/после).
2. EN/UK: переключение панели «Вид» переводит обвязку; черновые тексты перечислены в отчёте.
3. Grep-проверка: в файлах зоны нет кириллицы вне комментариев.
4. `npm run check:i18n` (ключи ru/en/uk синхронны), `npm run lint`, `npm run build`.

## Не делать (out of scope)

- Часы/адрес из Settings, metadata — другие шаги. Вёрстку не менять.
