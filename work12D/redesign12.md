## 1. Дизайн-система (расширение 12.html)

### 1.1 Цветовая палитра (обязательно к использованию)
```css
:root {
  --bg:   #faf5ec;  /* фон body, тёплый кремовый */
  --ink:  #22242a;  /* основной текст, границы, ВСЕ тени */
  --c1:   #e8b64c;  /* акцент 1: жёлтый/горчичный — тени, CTA fill, бейджи */
  --c2:   #7fae9e;  /* акцент 2: мятный/бирюзовый — тени, CTA line, chip-ы */
  --c3:   #d0785a;  /* акцент 3: терракота/коралл — тени, chip-ы, рамки фото */
  --white: #ffffff; /* карточки, подложки форм */
}
```
**Принцип 3-цветовой системы:** Каждый акцент = отдельная «категория слота конфигуратора» (c1/круглое, c2/треугольное, c3/зигзаг). Соответствие:
- **c1 (горчичный):** кнопки fill, тень card:nth-child(1), бейджи «в наличии», badge, hover навигации
- **c2 (мятный):** кнопки line, тень card:nth-child(2), chip в hero, тень CTA line
- **c3 (терракота):** тень card:nth-child(3), chip--2, рамка about .frame, тень about

**Запреты:** Никаких холодных синих, серых, фиолетовых. Допустимо: `#5a5d66` (приглушённый текст), `#8b8e97` (footer次要), `#d8dae0` (текст на тёмном фоне about).

### 1.2 Типографика
| Роль | Шрифт | Веса | Размеры (clamp) |
|---|---|---|---|
| Display / H1 (hero, footer big) | **Unbounded** | 800 | `clamp(2.6rem, 6.6vw, 5rem)` / `clamp(1.5rem, 3.6vw, 2.2rem)` |
| H2 (заголовки секций) | **Unbounded** | 800 | `clamp(1.7rem, 4vw, 2.6rem)` |
| H3 (карточки товаров, названия) | **Unbounded** | 600 | `1.05rem` |
| Body / UI / Описания | **Nunito** | 400, 600, 700 | `0.85–1.12rem`, `line-height: 1.6` |
| Цена (в карточках) | **Unbounded** | 800 | `1rem` |
| Бейджи / Дудл / Chip / Badge | **Unbounded** | 600 | `0.7–0.8rem`, uppercase |

**Правило:** Unbounded — **только** заголовки, цены, бейджи. Весь читаемый текст — Nunito. Unbounded weight 600 используется для дудлов и бейджей (легче, чем 800). Допускается font-weight: 400 Unbounded для footer次要 текстов.

### 1.3 Базовые UI-примитивы (переиспользуемые компоненты)

| Примитив | Описание | CSS-паттерн из 12.html |

### 1.4 Тени и глубина (signature)
- **Жёсткие тени без blur:** `box-shadow: 8px 8px 0 var(--ink)` — основной паттерн
- Цветные тени карточек: по `nth-child` (c1, c2, c3)
- Hover: `translate(-4px, -4px) rotate(-1deg)` + увеличение тени
- **Уровни:** 6px (кнопки навигации), 8px (карточки, hero), 10px (about frame), 12px (hero blob)
- Анимации: `transition: .25s` — только `transform` + `box-shadow`

### 1.5 Иконография
- Стиль: **жирные, геометрические, с заливкой** (не линейные, а filled shapes)
- Набор: телефон, почта, карта, инстаграм, телеграм, корзина/заявка, поиск, фильтр, стрелка, чекмарк, крестик, лупа, меню (burger), круг ▲ ● ■ (конструкторские)
- Размер: 24×24 viewBox, толщина 3px (match border)
- **Дополнительно:** Каждая категория → своя геометрическая иконка (circle / triangle / zigzag / square / hexagon / star)

### 1.6 Геометрический фон «Конфетти»
- `position: fixed; inset: 0; z-index: -1; pointer-events: none`
- 4 radial-gradient круга (`--c1`, `--c2`, `--c3`) + 1 diagonal stripe (`45deg linear-gradient`)
- **Для админки:** Адаптация фона — более приглушённый (opacity .3 на кругах, или отсутствие фона)
- **Для страниц без hero:** Можно включать/выключать через CSS class `.page--flat`

## 3. Навигация и глобальные элементы

### 3.1 Header (все публичные страницы)
- Классический горизонтальный header (`.header` из 12.html), sticky top
- **Лево:** Logo `Unbounded 800` + кружок-индикатор `--c3` (`.logo i`)
- **Центр/Право:** Nav-кнопки (pill-стиль с `--ink` бордером): **Вещи** (`/catalog`), **Собрать** (`/configurator`), **О нас** (`/about`), **Контакты** (`/contacts`)
- Hover: `background: var(--c1); transform: rotate(-2deg)` — конструкторский «сдвиг»
- **Админка:** Показывать иконку «⚙ Админ» в nav (только авторизованным). Внутри админки — header с лого и nav: Дашборд / Товары / Склад / Категории / Заявки / Настройки.
- **Мобильное:** Бургер → полноэкранное меню (card-стиль: каждый пункт = pill-кнопка на `--bg`)

### 3.2 Footer (все публичные страницы)
- **Два варианта** (выбор за дизайнером):
  - **Вариант 1 (текущий):** Центрированный CTA (Unbounded 800 «Напиши — что-нибудь соберём!»), контакты (Nunito), мини-копирайт
  - **Вариант 2 (расширенный):** Grid 3 колонки: Лево — лого + «Геометрия, которую можно надеть» (Unbounded), Центр — быстрые ссылки (Вещи / Собрать / О нас), Право — контакты + соцсети (иконки). Низ — копирайт
- В любом варианте: `confetti` фон продолжается (или убирается — опционально)

### 3.3 Хлебные крошки (внутренние страницы)
- Строка: `Главная / Вещи / Кулоны / Кулон «Зигзаг удачи»`
- Стиль: Nunito `0.85rem`, `#5a5d66` цвет, разделитель `›`, текущая `--ink` bold
- Pill-стиль для текущего (опционально): `--c1` bg, `--ink` border, 12px radius

### 3.4 Doodle-бейджи (подписи секций)
- Каждая секция имеет `.sec-title` с заголовком (Unbounded) + doodle-пill справа
- Doodle: `--c3` bg, белый текст, `--ink` border, `rotate(-3deg)`, pill-shape
- Примеры: `▲●■ миксуй!`, `.Handmade`, `Без повтора!`, `По инструкции`
- Формула: `[иконки-формы] + [глагол/прилагательное]`

Внутренний breakdown мелким Nunito: «Работа: X ₽ + Компоненты: Y ₽ = Z ₽». Кнопка «Оформить заявку»: btn--fill, тень `--c1`. |
| **Модалка заявки** | `.card` стилизация (24px radius, `--ink` border). Заголовок Unbounded. Фото-превью коллажа (thumb, `--ink` border). | **Мобильный конфигуратор** | Табы сверху. Таб «Коллаж»: canvas-area полная ширина. Таб «Слоты»: accordion, каждый слот раскрывается отдельно. Калькулятор — sticky bottom, полная ширина, поверх контента. |

- Анимация: fadeIn + scale(.95 → 1) `.2s`

### 4.3 Админ-таблицы (единый паттерн)
- Обёртка: `.card` (24px radius, `--ink` border, белый bg, без тени — админка «чище»)

- Действия: btn-icon по 2–3px, `--c1` bg
- Пагинация: pill-кнопки с `--ink` border, активная `--c1` bg

- [ ] Все 11 публичных страниц + 7 админ-экранов смакетированы во всех 3 брейкпоинтах
