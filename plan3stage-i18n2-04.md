# Задание агенту — i18n-2 · Шаг 4 из 8: Вывод через L() — товары

**Тип задачи:** замена вывода
**Зависимости:** i18n-2 · Шаги 1–2
**Связанные пункты плана:** `plan-3.md` §4
**Файлы зоны:** `app/(public)/product/[slug]/page.tsx`, `components/product/ProductCard.tsx`, `components/product/OrderModal.tsx` («Заявка на {name}»), витрина главной (`page.tsx` карточки товаров), `catalog/[slug]/page.tsx` (сетка товаров), SEO товаров

## Цель

Названия, описания, материалы/характеристики товаров рендерятся через `L(value, locale)`. RU не меняется.

## Шаги

1. Вывод `product.name`, `product.description` (и прочие текстовые поля из схемы products) → `L(...)` во всех местах витрины (карточка на полке, карточка товара, модалка заказа, SEO-ручной ввод как D-i18n-2).
2. Статичный второй абзац — уже UI-словарь (i18n-1 шаг 7), не трогать.
3. Проверить все места использования товаров: главная (избранное/новинки), каталог категории, «Рядом на полке», order-success (чек «товар»), OrderModal «Заявка на {name}».
4. RU-сверка всех мест.

## Критерии приёмки

1. RU: все тексты товаров те же (карточки, полки, модалки, чек).
2. EN/UK: тестовый товар с `{ru, en}` в dev-БД отображается per-locale; без en — фолбэк ru.
3. Grep зоны; `npm run lint`, `npm run build`.

## Не делать (out of scope)

- Комплектующие (шаг 5), Settings (шаг 6), автогенерация SEO (шаг 8).
