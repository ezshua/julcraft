# Этап 1.3 — Базовый layout и UI-каркас

**Тип задачи:** frontend / каркас страниц
**Зависимости:** `stage-1-1.md` (Next.js + Tailwind-тема с токенами из `style.css` готовы)
**Связанные пункты плана:** `plan-1.md` §3 (структура), §7 T-1.1 (layout), решения D-1a, D-8a

---

## Цель
Собрать корневой каркас сайта: `app/layout.tsx` с подключёнными шрифтами, sticky-шапка (`Header`) и подвал (`Footer`) по разметке `work1206D/mockup/home.html`, адаптивное мобильное меню. На выходе — публичный маршрут `/` с заглушкой контента, обрамлённый шапкой и подвалом, стилизованный исключительно токенами Tailwind (без shadcn).

## Решения, которые нельзя нарушать
- **D-1a:** стилизуем по **дефолтному** скину (`style.css`): тёплая палитра, шрифты **Shrikhand** (display) + **IBM Plex Mono** (body). НЕ добавлять «мемфис»-оформление (конфетти, жёсткие цветные тени c1/c2/c3) — это отложено.
- **D-8a:** никакого shadcn. Компоненты — обычные функциональные React-компоненты + Tailwind-утилиты.
- Опирайся на разметку `home.html` (блоки `header.topbar` и `footer.footer`) как на референс структуры и классов.

## Шаги
1. **Шрифты.** В `app/layout.tsx` через `next/font/google` подключить `Shrikhand` (переменная для `--font-display`) и `IBM_Plex_Mono` (для `--font-mono`/body). Пробросить как CSS-переменные; убедиться, что `tailwind.config.ts` `fontFamily.display/mono` на них ссылаются. `lang="ru"`.
2. **`<body>`:** классы `bg-cream text-brown font-mono antialiased`, базовый `line-height`.
3. **`components/layout/Header.tsx`:**
   - sticky-шапка: `sticky top-0 z-header bg-brown border-b-[6px] border-mustard`.
   - Логотип `JulCraft` (font-display, cream) + мелкая подпись (напр. «мастерская украшений»).
   - Навигация: Главная, Каталог, Конфигуратор, О нас, Контакты (ссылки на `/`, `/catalog`, `/configurator`, `/about`, `/contacts` — роуты пока могут 404, каркас важнее). Активный пункт выделять классом `is-active`.
   - `icon-btn` с телефоном + бургер (виден только на мобильных).
   - Мобильное меню (`mobile-menu`): открывается по бургеру, закрывается по крестику/клику по ссылке. Состояние — `useState`, без сторонних библиотек.
4. **`components/layout/Footer.tsx`:** по `home.html` footer — `f-grid` (бренд + часы работы + связь/соцсети), копирайт с dashed-границей. Соц-иконки — inline SVG (телефон/почта/инстаграм/телеграм) из `design-system.html` §5 или `home.html`.
5. **Компоновка:** в `app/layout.tsx` обернуть `<Header/>`, `{children}`, `<Footer/>`. При необходимости группа `(public)` — не обязательно на этом этапе.
6. **Заглушка контента:** `app/page.tsx` → секция-«вывеска» (`signboard`) с заголовком `JulCraft`, подзаголовком и CTA-кнопками (ведут на `#`), чтобы визуально проверить тему. Никакой бизнес-логики.
7. **Адаптив:** навигация скрывается `<=820px` (классы Tailwind `hidden md:flex` и т.п.), бургер показывается; мобильное меню на всю высоту (`z-burger`).

## Критерии приёмки
- `npm run dev` → `/` отдаёт шапку + подвал + заглушку.
- Шрифты Shrikhand (заголовки) и IBM Plex Mono (текст) применяются.
- Цвета/тени/радиусы берутся только из Tailwind-токенов (brown/mustard/rust/olive/cream/paper…), shadcn отсутствует.
- На ширине ≤820px навигация сворачивается в бургер, мобильное меню открывается/закрывается.
- Разметка Header/Footer соответствует структуре `home.html`.

## Не делать (out of scope)
- Контент страниц (главная-витрина, каталог, карточка, конфигуратор, админка) — этапы 2–5.
- Адаптацию финального скина «Мемфис» и конфетти-фон (отложено на конец).
- Кастомные кнопки/инпуты как переиспользуемые UI-примитивы — это появится в этапе 3; здесь достаточно инлайн-классов.
