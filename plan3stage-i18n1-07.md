# Задание агенту — i18n-1 · Шаг 7 из 12: Карточка товара и заявка (OrderModal, Avail)

**Тип задачи:** вынос строк в словарь
**Зависимости:** i18n-1 · Шаг 1
**Связанные пункты плана:** `plan-3-i18n-constants.md` §1.4
**Файлы зоны:** `app/(public)/product/[slug]/page.tsx`, `components/product/ProductCard.tsx`, `ProductGallery.tsx`, `OrderModal.tsx`, `components/ui/Avail.tsx`

## Цель

UI-строки товарной зоны — в словарь (namespace `product`). SEO-фолбэк (page.tsx 20) — шаг 11. Контент товара (название, описание, характеристики) — i18n-2.

## Особое внимание — гибриды строка+данные

- `Avail.tsx` (16–72): «⏳ резерв до {день}» — день недели из даты (`reserveDayFull`, `lib/format.ts`). Локализованные дни — из словаря, функция выбора per-locale; «⏳ под заказ · {n} дн» — plural; «✔ в наличии», «⏳ резерв», «✕ нет на складе» — простые ключи (короткая/полная формы для полки и модалки).
- Статичный второй абзац описания (page.tsx 43–44) — это UI-строка (одинакова для всех товаров), ключ `product.staticSecondParagraph`.

## Шаги

1. Ключи `product.*` по аудиту §1.4 (сверять строки с кодом):
   - page.tsx: крошки «Главная / Каталог» (75–76), «Собрать похожий →» (120), «Рядом на полке» + подпись (128–129), статичный абзац (43–44);
   - ProductCard: бейджи «новинка», «избранное» (15–16);
   - ProductGallery: alt «Вид {n}» (59);
   - OrderModal (52–134): ошибки отправки (2×), «Заказать», «Заявка на {name}», aria-label «Закрыть», «{цена} · {наличие} · мастер свяжется сама», лейблы «Имя / Как к вам обращаться», «Контакт / Телефон, email или Telegram», «Комментарий / Цепочка длиннее/короче…», «Отправить заявку», «Отмена», «*** без предоплаты — цена и срок в чеке после звонка ***». `{наличие}` — вывод из ключей Avail соответствующей локали;
   - Avail: все формы (см. выше), plural «дн» → `plural(n, dict.product.days, locale)`.
2. Client-компоненты (OrderModal, Avail и др.) — словарь пропсами из серверной страницы.
3. EN/UK — черновой перевод, список — в отчёт.

## Критерии приёмки

1. RU: карточка товара текстово идентична во всех состояниях наличия (`in_stock`, `reserve`, `made_to_order`, `out_of_stock` — проверить на сид-данных, там есть все варианты).
2. EN/UK: переключение переводит зону; «резерв до пятницы» и «под заказ · 7 дн» на EN/UK корректны.
3. Grep зоны — 0 кириллицы вне комментариев; `check:i18n`; `npm run lint`, `npm run build`.

## Не делать (out of scope)

- SEO-строки (шаг 11), контент товара из БД (i18n-2), логика Avail/резервов не меняется.
