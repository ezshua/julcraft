## 4. Утверждённая архитектура (вариант B, закрыт решениями D-i18n-1…7)

Cookie-based i18n (переиспользование механизма валюты: cookie `julcraft-locale` + localStorage, панель «Вид», 0 новых зависимостей) + JSON-локализация контента (`{"ru":..,"en":..,"uk":..}` + фолбэк на ru) + локализация админки.

Этапы (каждый — отдельное задание агенту по образцу `plan2stage*.md`; детальная декомпозиция на атомарные шаги с отдельными файлами-заданиями — `plan3stages.md` + `plan3stage-i18nN-MM.md`):

- [ ] **i18n-1: Словарь витрины.** Вынос UI-строк витрины в словари (`lib/dictionaries/ru|en|uk.ts`), `lib/i18n.ts` (чтение locale, `plural()` per-locale, интерполяция), динамический `<html lang>`, переключатель RU/EN/UK в панели «Вид» (skin-switcher.js), SEO-словарь статических страниц (EN — D-i18n-7). Витрина на RU визуально не меняется (приёмка: сравнение с макетом).
- [ ] **i18n-2: Модель контента.** Тип `localizedString`, миграция данных (конвертация одиночных строк в `{ru}`), поля EN/UK в модалках админки (расширение форм без изменения вёрстки, по аналогии с D-13), вывод с фолбэком `locale → ru`. SEO товаров/категорий: ручной ввод хранится как введён (D-i18n-2), автогенерация — транслит EN (TRANSLIT из `lib/format.ts`).
- [ ] **i18n-3: Дефолты сервера.** Переменные `.env` (`DEFAULT_SKIN`, `DEFAULT_CURRENCY`, `DEFAULT_LOCALE`): скин и язык — стартовые значения для новых клиентов (приоритет: cookie клиента → .env; в админку не выносятся, поле «валюта по умолчанию» из Settings остаётся для UI-валют), валюта — .env перекрывает Settings (D-i18n-6), документация в README-deploy и `.env.example`.
- [ ] **i18n-4: Локализация админки.** Перевод UI админки и её API-ошибок (~530 строк) через тот же словарный механизм (D-i18n-3); язык админки — по тому же cookie (отдельного переключателя не делаем).
- [ ] **i18n-5: Переводы контента.** Агент готовит пакет переводов демо-сида RU→EN/UK (D-i18n-4): категории, слоты, типы, комплектующие, товары, Settings-тексты (чеки, принципы, часы, адрес). Боевой контент дальше наполняется мастером через админку (фолбэк — RU).
- [ ] **i18n-6 (опционально):** шов SEO: sitemap для EN-транслит-URL при необходимости, ревизия metadata API-ошибок, Telegram-шаблоны остаются на русском (язык мастера).

## 5. Решения (зафиксировано 2026-09-07)

| # | Вопрос | Решение |
|---|---|---|
| D-i18n-1 | Набор языков | **RU + EN + UK**; RU — базовый и фолбэк для всего контента |
| D-i18n-2 | SEO-мультиязычность | Без URL per-языка (вариант B, cookie); SEO-поля товаров/категорий: ручной ввод хранится как введён (на каком языке ввёл мастер — таком и остаётся); автогенерация — английский транслит (таблица TRANSLIT из `lib/format.ts`) |
| D-i18n-3 | Админка и API-ошибки | **Локализовать полностью** на 3 языка (вместе с витриной; ~530 строк админки + ~100 админ-API ошибок) |
| D-i18n-4 | Переводы контента БД | Первый пакет (демо-сид RU→EN/UK) готовит агент; боевой контент мастер заполняет в админке (поля EN/UK, фолбэк на RU) |
| D-i18n-5 | Переключатель языка | В панели «Вид» (skin-switcher.js) рядом со скином и валютой; cookie `julcraft-locale` + localStorage, приоритет: cookie клиента → `.env` дефолт → RU |
| D-i18n-6 | Дефолты при старте сервера | `.env`: `DEFAULT_SKIN` (memphis/handmade), `DEFAULT_CURRENCY`, `DEFAULT_LOCALE` (ru/en/uk). Валюта: `.env` перекрывает Settings (если задан). Скин/язык: действуют для клиентов без сохранённого выбора |
| D-i18n-7 | Язык автогенерации SEO статических страниц | **Английский текст** (готовый копирайт EN в словаре metadata); транслит — только для автогенерации имён/строк товаров и категорий из русского |
