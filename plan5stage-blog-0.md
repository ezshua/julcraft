# Задание агенту — blog · 0: Макеты блога

**Тип задачи:** макеты (дизайн-подготовка, без кода сайта)
**Зависимости:** —
**Связанные пункты плана:** `plan-5-blog.md` §1 (B1, B5, B7), §4–6, §8; `plan-2.md` §0 (макет — источник истины), §2 (карта соответствия)
**Файлы зоны:** `mockup/blog.html`, `mockup/blog-post.html`, `mockup/admin/blog.html`, `mockup/admin/blog-editor.html`, `mockup/index.html`, `plan5stages-blog.md`, `plan5stage-blog-*.md`

## Общие правила

- `mockup/assets/css/*` и `mockup/assets/js/*` **не трогать** — стили переиспользуются как есть.
- Только существующие блоки и классы макетов: `.topbar`, `.mobile-menu`, `.crumbs`, `.signboard`, `.zigzag`, `.sect`, `.shelf`, `.item`, `.chip`, `.tag`, `.btn`, `.board`, `.dropzone`, `.field`, `.page-btn`, `.empty-state`, `.receipt`, `.admin-wrap`, `.page-title`, `.modal` — ничего не изобретается.
- Маскеты статичны: без JS и без сборки, ссылки между страницами ведут на другие `.html`.
- Демо-тексты — в тоне JulCraft (тёплый, «старая лавка»), как в существующих макетах.
- Цвета и типографика — из обоих скинов сразу, чтобы этапы 4/5/7 переносили вёрстку 1:1 в оба CSS-файла.

## Задания

**0.1** План в репозитории
- `plan-5-blog.md` (создан), `plan5stages-blog.md` (реестр), `plan5stage-blog-0.md` … `plan5stage-blog-8.md` — по файлу на этап с блоками «Тип задачи / Зависимости / Файлы зоны / Общие правила / Задания / Критерии приёмки / Не делать».

**0.2** `mockup/blog.html` — список блога
- Меню в порядке B7: Главная · Каталог · Конфигуратор · **Блог** (активен) · О нас · Контакты; тот же порядок в `.mobile-menu`.
- Крошки Главная → Блог, `.signboard--small` с вывеской и подписью, `.zigzag`.
- Фильтр по тегу чипами `.chip` + ссылка «все записи».
- Навигация «год → месяц»: годы списком, месяцы выбранного года — ссылками.
- Группы дат: заголовок вида «сентябрь 2026», внутри карточки записей (обложка, заголовок, кратко, дата).
- Записи в разных месяцах, чтобы было видно и группировку, и навигацию.
- Пагинация `.page-btn` (демо — две страницы).
- Вариант `empty-state` ниже или отдельным блоком с подписью.

**0.3** `mockup/blog-post.html` — страница записи
- Крошки Главная → Блог → Заголовок.
- `h1`, дата, строка тегов (ссылки на список с фильтром).
- Обложка.
- Блок `.prose` со **всеми** поддерживаемыми конструкциями markdown: `##`/`###`, **жирный**, *курсив*, ~~зачёркнутый~~, `код`, блок кода, маркированный и нумерованный списки, список задач, таблица, цитата, картинка, внешняя ссылка, разделитель.
- Ссылка «← все записи», соседние записи (предыдущая / следующая).

**0.4** `mockup/admin/blog.html` — панель мастера
- Пункт Блог в `.topbar` и `.mobile-menu` между Категориями и Настройками.
- Две вкладки (по образцу вкладок категорий): **Записи** и **Теги**.
- Вкладка Записи: заголовок страницы + doodle + кнопка «Новая запись»; фильтры статуса (все / черновики / опубликованные) и поиск; список карточек: обложка, заголовок со slug, дата, статус-бейдж (оба варианта — черновик и опубликован), чипы тегов, действия (править, опубликовать / снять с публикации, открыть на сайте, удалить).
- Вкладка Теги: список с переименованием, переключателем активности, удалением и полем создания нового тега.
- Пустое состояние для обоих списков.

**0.5** `mockup/admin/blog-editor.html` — редактор
- Поля: Заголовок, Slug (с подсказкой формата), Кратко, Обложка (`.dropzone` + превью).
- Теги: чипы активных тегов с переключением + поле «новый тег».
- Панель markdown-кнопок над двумя колонками **Текст** | **Предпросмотр**.
- Вкладки RU/EN/UK над редактором.
- Секция SEO (metaTitle, metaDescription).
- Кнопки Сохранить / Опубликовать / Снять с публикации / Удалить.
- Служебные подписи действий (disabled-состояние Сохранить, пометка «есть несохранённые правки»).

**0.6** Демо-контент и хаб
- 4 опубликованные записи (разные месяцы и годы), 1 черновик, 3 тега. Тексты пойдут в сид на этапе 8 — держим в одном месте.
- Обложки в макетах ссылаются на существующие файлы `mockup/assets/` или на `../assets/` так же, как это сделано в существующих макетах.
- `mockup/index.html`: карточки `mockup/blog.html`, `mockup/blog-post.html` в публичной группе и `admin/blog.html`, `admin/blog-editor.html` в admin-группе.

## Критерии приёмки

1. Все четыре макета открываются в браузере без JS-ошибок, ссылки переключают страницы.
2. Вёрстка использует только существующие классы и токены обоих скинов.
3. В макете записи присутствуют все поддерживаемые конструкции markdown.
4. Порядок пунктов меню — как в B7 (публичное) и Блог между Категориями и Настройками (админка).
5. `mockup/index.html` содержит карточки всех четырёх страниц.
6. Руководитель утвердил макеты — до старта этапа 1.

## Не делать

- Код сайта, словари, БД, API — это этапы 1+.
- Не править `mockup/assets/css/*` и `mockup/assets/js/*`.
- Не добавлять в макеты того, чего нет в плане (RSS, комментарии, отложенная публикация).
