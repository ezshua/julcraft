# Задание агенту — blog · 8: Демо-сид, документы и сквозная приёмка

**Тип задачи:** контент + инфраструктура + приёмка
**Зависимости:** blog · 4, 5, 6, 7
**Связанные пункты плана:** `plan-5-blog.md` §2 (критерии приёмки направления), §9
**Файлы зоны:** `site/scripts/seed.ts`, `site/scripts/check-seed.ts`, `docs/deploy-snapshot.md`, `README-deploy.md`, `mockup/index.html`, `plan-5-blog.md`

## Общие правила

- `npm run db:seed` — **только** с `DATABASE_URL` на временной БД, боевую не трогать.
- Тон RU-текстов — JulCraft (тёплый, «старая лавка»); EN — естественный английский, UK — украинский, без машинного перевода.
- Коммиты — только по явной команде.

## Задания

**8.1** `site/scripts/seed.ts`:
- 3 тега;
- 4 опубликованные записи в разных месяцах, с тегами, обложками, markdown-текстом; EN и UK — минимум у двух записей (проверка фолбэка);
- 1 черновик (не должен попадать на витрину);
- обложки демо — существующие файлы из `public/uploads/products/` (как сделано для категорий), т.к. `public/uploads/blog/` в git не входит.

**8.2** `site/scripts/check-seed.ts`: счётчики записей и тегов + ассерты:
- опубликованные отдаются `getPublishedPosts()`;
- черновика в списке нет;
- связи `blogPostTags` целы;
- все обложки — существующие файлы.

**8.3** Документы деплоя:
- `docs/deploy-snapshot.md` — в списке каталогов uploads и таблиц добавить `blog`, `blogPosts`, `blogTags`, `blogPostTags`;
- `README-deploy.md` — проверить права на новую подпапку (создаётся `mkdir -p`; setgid-биты менять не нужно).

**8.4** Сквозной регресс: `npm run check:i18n`, `check:markdown`, `check:blog`, `check:seed` (на временной БД), `lint`, `build`, `snapshot:check`.

**8.5** Приёмка по макетам в **обоих** скинах; ручной чек-лист:
- [ ] меню (B7) и мобильное меню;
- [ ] список: группировка по датам, навигация, фильтр тегов, пагинация;
- [ ] запись: все конструкции markdown, теги, соседние записи;
- [ ] редактор: предпросмотр, картинки, теги, публикация/снятие;
- [ ] черновик не виден публично и не попадает в sitemap;
- [ ] EN/UK-фолбэк;
- [ ] оба скина.

**8.6** Отметить чекбоксы в `plan-5-blog.md`, внести запись в журнал изменений.

## Критерии приёмки

1. Все семь проверок зелёные.
2. Чек-лист пройден полностью.
3. Замечания руководителя закрыты.

## Не делать

- Не коммитить без команды.
- Не добавлять новые поля или фичи сверх `plan-5-blog.md`.
