# Задание агенту — i18n-1 · Шаг 2 из 12: Динамический `<html lang>`

**Тип задачи:** точечная правка
**Зависимости:** i18n-1 · Шаг 1 (`lib/i18n.ts`)
**Связанные пункты плана:** `plan-3.md` §4 (i18n-1); `plan-3-i18n-constants.md` §1.1 (`app/layout.tsx` ~строка 12)

## Цель

`<html lang>` отражает выбранный locale (сейчас захардкожен `lang="ru"`), RU-поведение не меняется.

## Правила

- §0 без изменений; вёрстка/классы не трогаются. Коммиты — только по команде.

## Шаги

1. `site/app/layout.tsx`: сделать layout async, `const locale = await getLocale()`, `<html lang={locale}>`.
2. Проверить влияние `cookies()` в корневом layout: рендер становится динамическим. Сайт уже SSR-динамический (SQLite, cookie валюты), но прогнать `npm run build` и убедиться, что нет неожиданных ошибок статической генерации (`loading.tsx`, `sitemap.ts`, `robots.ts`, `not-found.tsx`). При блокере — вопрос руководителю, не обходить самостоятельно.

## Критерии приёмки

1. `view-source` при пустом окружении: `lang="ru"`; вручную выставить cookie `julcraft-locale=en` (devtools; переключателя ещё нет) → перезагрузка → `lang="en"`. Неверное значение cookie → `ru`.
2. RU-витрина визуально не изменилась; `npm run lint`, `npm run build`.

## Не делать (out of scope)

- Переключатель языка в панели «Вид» — следующий шаг. Слой `.env` — i18n-3.
