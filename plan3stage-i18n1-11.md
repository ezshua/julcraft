# Задание агенту — i18n-1 · Шаг 11 из 12: SEO словарь статических страниц (EN-копирайт)

**Тип задачи:** вынос строк в словарь + первые «боевые» EN-тексты
**Зависимости:** i18n-1 · Шаги 1–10 (все зоны вынесены)
**Связанные пункты плана:** `plan-3.md` §5 (D-i18n-7); `plan-3-i18n-constants.md` §1.2–§1.8 (SEO-строки)
**Файлы зоны:** `app/(public)/*/page.tsx` (metadata-функции), `app/layout.tsx` (дефолтный metadata)

## Цель

`title`/`description` всех статических страниц — в словарь (namespace `meta`), по решению D-i18n-7: RU-тексты переносятся как есть, EN — готовый копирайт (не черновой), UK — черновой/перевод по образцу EN.

## Контекст (D-i18n-2/D-i18n-7)

- SEO товаров/категорий из БД: ручной ввод хранится как введён — это i18n-2. Здесь только статические страницы: главная, каталог (+[slug] фолбэк), конфигуратор (+[slug]), контакты, about, order-success, not-found, error.
- Динамический `generateMetadata` получает locale так же, как страницы (`getLocale()`).

## Шаги

1. Ключи `meta.*` per-страница: `{page}.title`, `{page}.description` (у некоторых страниц 2 варианта description — сохранить оба). Включая фолбэки каталога/конфигуратора ([slug] без данных).
2. RU-значения — байт-точно из текущего кода.
3. EN — готовый копирайт (написать как тексты сайта, тон JulCraft; это единственный шаг, где EN не «черновик»); UK — по образцу.
4. Заменить хардкод в `metadata`/`generateMetadata` на `t()`. Корневой `app/layout.tsx` metadata-шаблон («JulCraft» + суффиксы) — тоже в словарь.
5. Отчёт: таблица RU/EN/UK title+description всех страниц для ревью руководителем.

## Критерии приёмки

1. RU: `<title>`/`<meta name="description">` всех статических страниц идентичны текущим (сверка до/после через view-source или curl).
2. EN: страницы отдают EN-копирайт (cookie `julcraft-locale=en`).
3. Grep: в zone-файлах нет кириллицы вне комментариев; `check:i18n`; `npm run lint`, `npm run build`; `sitemap.ts`/`robots.ts` не изменились.

## Не делать (out of scope)

- SEO товаров/категорий из БД и транслит — i18n-2. hreflang — не делаем (вариант B). sitemap — не трогать.
